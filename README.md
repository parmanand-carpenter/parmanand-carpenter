### About

Blockchain developer with 3+ years on Ethereum. I take Layer-2 rollups from contract
deployment all the way to running them in production: smart contracts, the L2 node
stack, bridges, and the DevOps and security that come with holding real value on-chain.

- Shipped and operate a production OP Stack L2 with a custom gas token on Ethereum mainnet
- Work the full stack of a chain: sequencer, batcher, proposer, challenger, fault proofs
- Day-to-day focus on node operations, security hardening, and uptime

### Featured Work

**OP Stack Layer-2 Rollup** · [Xhavic-Blockchain](https://github.com/parmanand-carpenter/Xhavic-Blockchain)
A full Layer-2 on the OP Stack: a six-service node stack (execution engine, sequencer,
batcher, proposer, challenger, dispute monitor) in Docker, settling on Ethereum with
EIP-4844 blobs. The same stack now runs a custom-gas-token chain in production on
mainnet, with a fixed 1,000,000,000-token supply, a self-hosted L1 node, an L1-to-L2
bridge tested with real funds, a public RPC over SSL, and a block explorer.
